# Used libraries / data model file 

## Libraries
The libraries are generated in the docs folder by executing in root folder

- `./mvnw dependency:list > <filename>`
- `./mvnw dependency:tree > <filename>`

The script `./build.sh` is also doing the same and extracts version and file name from project.properties / README.md.

The expected output after execution of the script will be as follows :

```bash
./build.sh 
Start Build and documentation
module: mc3s-b2x-auth
Version: <Version>
....
generating reports ...
list
tree

available reports ... 

generate datamodel.png

```

## How to generate model file

### Step 1 - generate UML file

The plant UML is generated by using mvn profile documentation.

`./mvnw git-code-format:format-code clean install -P documentation`

This will create a model [file in plantuml format](uml/schemas.plantuml) from remote URL.

### Step 2 - generate png file

Execute `./build.sh` from repo root folder.
This will create [png file](images/datamodel.png))
